How to reference the project

When writing an article, guide or review, include the project name, author and version. Linking to a specific release helps readers find the version you describe.

Roman Tselischev (DjGreeZ). UniFi-AmneziaWG: AmneziaWG in the UniFi interface. Version 0.3.2, November 5, 2026. Release v0.3.2 on GitHub.

  • Project website — overview, installation and documentation.
  • Repository — current materials and development discussions.
  • Release 0.3.2 — a version-specific reference.
  • Source archive for 0.3.2 — integration code and bundled components.

Source code and licenses

The archive contains the integration code, AWG engine sources and dependency licenses. Individual components may have different terms. The published 0.3.2 archive does not specify a separate license covering the entire integration; source availability does not establish one license for the whole project.

UniFi-AmneziaWG is an independent experimental project and is not affiliated with Ubiquiti. Version 0.3.2 identifies the integration, not the AmneziaWG protocol.
