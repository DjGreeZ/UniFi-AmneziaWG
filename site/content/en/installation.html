Compatibility and requirements

You need an ARM64 / aarch64 UniFi gateway, root access over SSH and a client .conf from your AmneziaWG server. The integration does not provide a VPN server.

Tested combinations listed in the release README
DeviceUniFi OSUniFi Network
UDR75.1.34+10.6.109+
UDM5.1.33+10.6.101+
UDM Pro5.1.34+10.6.109+

The code requires at least OS 5.1.33 and Network 10.6.101. Version numbers are only the first check: the installer also verifies paths and SHA-256 hashes of active interface files. The catalog includes Network 10.6.101 and 10.6.109. The “+” notation from the README does not imply support for every future update. Testing on UDM SE has not been separately confirmed.

Before installation: back up UniFi, keep SSH access to the gateway and disable automatic updates for UniFi OS and Network. Updates have not been tested; the integration is not guaranteed to survive them. This project is not affiliated with Ubiquiti.

Install over SSH

Connect to the gateway as root over SSH and run the command for release v{{version}}:

SSH / SHELL
curl -fsSL https://raw.githubusercontent.com/DjGreeZ/UniFi-AmneziaWG/v{{version}}/install.sh -o /tmp/awg-install.sh && sh /tmp/awg-install.sh

Review the downloader before running it. It downloads this release's package and verifies its SHA-256 checksum against the published file. Engines, the panel and services are installed in /data/awg-native; original interface files are backed up. No on-device compilation is required.

If the installer reports incompatible interface files, keep the error and your UniFi version numbers for an issue report. Do not replace interface files manually.

Your first connection

  1. Open UniFi using the gateway's local IP address. The integration menu does not appear through unifi.ui.com.
  2. Go to Settings → VPN → AmneziaWG Client, select the add-connection button and upload your original AWG configuration.
  3. Select the newly created profile in native routing policies. Assign the intended devices or networks and enable Kill Switch.
  4. Check the connection state and external IP from a device assigned to the policy. Confirm that traffic counters increase.
  5. To add failover, create a separate connection and select it as the primary connection's backup. Each connection needs its own AWG client key.

The configuration must contain one [Peer] and one IPv4 tunnel address. AllowedIPs must include 1.1.1.1 for connectivity checks. IPv6 through the VPN is not supported. Configure device DNS in UniFi; the DNS setting in the AWG file is not automatically applied to the LAN.

Migrating from 0.2.x

Connections are not migrated automatically. Save the original AWG configurations outside the gateway first. Remove or reassign the related UniFi policies and VPN profiles, then fully remove the old integration using the command below. Install v{{version}} and recreate your connections afterwards.

DELETES CONFIGURATIONS AND KEYS
sh /data/awg-native/uninstall.sh --purge

Removing the integration

First remove or reassign the associated UniFi policies and VPN profiles. To remove the integration while keeping configurations and keys:

KEEP CONFIGURATIONS
sh /data/awg-native/uninstall.sh

For full removal, use --purge as in the command above: it also deletes configurations and keys. Refresh the UniFi page after removal.
