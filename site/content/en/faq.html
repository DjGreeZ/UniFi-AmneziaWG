Can I install Amnezia VPN on UniFi?

On the tested UniFi gateways, this project lets you connect to an AmneziaWG server. It adds an AWG protocol client and panel to UniFi OS; devices on your network use the VPN through gateway routing policies. Start with the step-by-step AmneziaWG installation guide for UniFi and check your model and firmware versions.

Should I import my Amnezia config into WireGuard or AmneziaWG Client?

Import the original AWG file into AmneziaWG Client. The integration automatically creates a native WireGuard profile as a local adapter. Importing the original configuration into a standard WireGuard client does not replace the AmneziaWG engine. If you only have a vpn:// key, obtain a native .conf file for your router first.

Do I need a separate VPN server?

Yes. This project installs an AmneziaWG client on a UniFi gateway. You need a reachable AWG server and its client .conf file. The project does not provide VPN servers, subscriptions or accounts.

How many connections can I add?

Version 0.3.2 supports up to four AWG connections. The panel also checks UniFi’s limit of four active VPN clients, including other VPN connections. Each AWG connection needs a separate client configuration with a unique private key; reusing the same key is rejected.

Do routing policies change during failover?

No. The same native UniFi WireGuard profile remains in place while its AWG exit changes. The assigned backup must be enabled and pass its connectivity check. It uses one of the four connection slots. See how failover works for details.

Why is the DNS setting from my AWG file not applied?

LAN DNS is configured in UniFi. The integration does not copy DNS settings from an imported AWG file to your local network. Configure routing policies and DNS for the relevant devices in UniFi.

Is IPv6 supported?

This version does not support IPv6 over the VPN. A connection requires one IPv4 tunnel address. Do not assume that device IPv6 traffic will pass through AWG.

Why is the panel missing on unifi.ui.com?

The integration adds a section to the local UniFi interface. Open the gateway’s local IP address and go to Settings → VPN → AmneziaWG Client. This section is not available through the unifi.ui.com cloud portal.

Can I access the AWG panel remotely?

Yes, after enabling remote access in the local panel. It uses a separate password, an IP or subnet allowlist and HTTPS with a self-signed certificate. A reachable IPv4 address and port are required. The URL must use https://IPv4:port; domain names are not currently supported. Remote access is disabled by default and exposes only the AWG panel.

Why does the check need 1.1.1.1?

The service checks HTTPS connectivity to 1.1.1.1 through the tunnel, so that address must be included in AllowedIPs. The displayed check time measures the time until the HTTPS response starts. It is not an ICMP ping or a VPN throughput test.

Can I update UniFi OS and Network?

Automatic updates have not been tested; disable them before installation. The installer checks UI files as well as version numbers. A newer UniFi release may be incompatible. Recovery after a reboot does not guarantee recovery after an update. See the compatibility requirements.

How do I upgrade from 0.2.x?

There is no automatic migration. Save your original AWG configurations, remove the old integration and its associated VPN profiles and policies, then install 0.3.2 and add the connections again. Follow the steps in the installation guide.
