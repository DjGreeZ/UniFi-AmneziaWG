AMNEZIA НА РОУТЕРЕ

Как подключить Amnezia
к UniFi?

Установите интеграцию по SSH, загрузите конфиг AmneziaWG и выберите устройства для VPN в политиках UniFi.

Проект добавляет клиент протокола AmneziaWG в UniFi OS. На шлюзе работает VPN-подключение, а устройства домашней или рабочей сети используют его по выбранным правилам. Для начала нужен ваш AWG-сервер и его файл конфигурации.

Как установить AmneziaWG на UniFi: пошаговая инструкция →

01 / ПОДКЛЮЧЕНИЯ

Импортируйте конфиг

Загрузите готовый .conf своего AWG-сервера. Интеграция создаст локальный WireGuard-профиль, доступный в политиках UniFi.

02 / РЕЗЕРВИРОВАНИЕ

Назначьте резерв

Выберите другое подключение как запасной выход. При отказе основного сервера политики останутся прежними. Автоматический возврат можно настроить.

03 / НАБЛЮДЕНИЕ

Следите за связью

Смотрите скорость, месячный трафик, историю доступности и события переключения. Данные о трафике сохраняют привязку к исходному профилю.

СОВМЕСТИМОСТЬ

Проверенные устройства.
Понятные границы.

Интеграция предназначена для шлюзов UniFi на ARM64. Для установки нужен root-доступ по SSH. Готовые движки входят в пакет.

Это тестовый независимый проект. Установка меняет файлы интерфейса UniFi; перед началом сохраните резервную копию.

«+» не гарантирует работу всех новых версий. Установщик проверяет файлы интерфейса. В каталоге релиза есть Network 10.6.101 и 10.6.109. Обновления UniFi не тестировались; автообновления следует отключить.

UDM SE и другие модели не входят в опубликованный список проверенных устройств.
