Установка AmneziaWG
на роутер UniFi.

Пошаговая настройка Amnezia на UniFi через протокол AmneziaWG 3.1: от файла конфигурации до VPN для выбранных устройств. Инструкция для интеграции 0.3.2.

Установить Amnezia на UniFi с помощью этого проекта означает добавить клиент протокола AmneziaWG в UniFi OS. Он подключает роутер к вашему AWG-серверу и позволяет выбрать устройства для VPN в политиках UniFi. Настольное приложение AmneziaVPN на шлюз не устанавливается.

На каких UniFi работает: UDR7, UDM и UDM Pro

Нужен шлюз UniFi на ARM64 / aarch64, доступ по SSH от root и готовый клиентский .conf AmneziaWG 3.1. Сервер и экспортируемый конфиг должны использовать AWG 3.1. Интеграция не предоставляет VPN-сервер.

Проверенные сочетания по README релиза
МодельUniFi OSUniFi Network
UDR75.1.34+10.6.109+
UDM5.1.33+10.6.101+
UDM Pro5.1.34+10.6.109+

Минимальные версии в коде — OS 5.1.33 и Network 10.6.101. Но номер версии — лишь первая проверка: установщик сверяет пути и SHA-256 активных файлов интерфейса. Каталог содержит сборки Network 10.6.101 и 10.6.109. Знак «+» из README не означает поддержку любого будущего обновления. Проверка UDM SE отдельно не подтверждена.

Перед установкой: сохраните резервную копию UniFi, обеспечьте доступ к шлюзу по SSH и отключите автообновления UniFi OS и Network. Обновления не тестировались; сохранность интеграции после них не гарантируется. Проект не связан с Ubiquiti.

Как получить конфиг AmneziaWG 3.1 для роутера

Если вы управляете своим сервером через AmneziaVPN, сначала проверьте, что на нём настроен протокол AmneziaWG 3.1. Затем в приложении откройте Share / «Поделиться» → AmneziaWG native format и сохраните файл .conf. Этот способ экспорта описан в официальной документации Amnezia.

Для UniFi-AmneziaWG нужен именно нативный AWG-конфиг версии 3.1 с секциями [Interface] и [Peer]. Само расширение .conf не подтверждает версию протокола. Ключ-ссылка vpn:// напрямую не импортируется. Если VPN выдал провайдер, запросите у него конфиг AWG 3.1 и отдельный клиентский ключ для роутера. Доступность экспорта зависит от используемого сервиса.

Установка по SSH

Подключитесь к шлюзу по SSH от root и выполните команду для релиза v0.3.2:

SSH / SHELL
curl -fsSL https://raw.githubusercontent.com/DjGreeZ/UniFi-AmneziaWG/v0.3.2/install.sh -o /tmp/awg-install.sh && sh /tmp/awg-install.sh

Просмотреть загрузчик перед запуском. Он скачивает пакет этого релиза и проверяет SHA-256 по опубликованной контрольной сумме. Движки, панель и службы устанавливаются в /data/awg-native; оригиналы изменяемых файлов сохраняются. Компиляция на шлюзе не нужна.

Если установщик сообщает о несовместимых файлах интерфейса, сохраните текст ошибки и версии UniFi для сообщения в Issues. Не подменяйте файлы интерфейса вручную.

Первое подключение

  1. Откройте UniFi по локальному IP шлюза. Через unifi.ui.com раздел интеграции не отображается.
  2. Откройте Settings → VPN → AmneziaWG Client, нажмите «Добавить подключение» и загрузите нативный конфиг AmneziaWG 3.1.
  3. В штатных политиках маршрутизации выберите созданный профиль. Назначьте нужные устройства или сети и включите Kill Switch.
  4. Проверьте состояние подключения и внешний IP с устройства, которому назначена политика. Убедитесь, что растут счётчики трафика.
  5. Для резерва добавьте отдельное подключение и выберите его в настройках основного. У каждого подключения должен быть свой клиентский ключ AWG.

Конфиг должен содержать один [Peer] и один IPv4-адрес туннеля. AllowedIPs должен включать 1.1.1.1 для проверки связи. IPv6 через VPN не поддерживается. DNS устройств задаётся в UniFi; DNS из AWG-файла автоматически в LAN не переносится.

Что проверить, если VPN не работает

СимптомПервая проверка
Нет раздела AmneziaWG ClientОткройте локальный IP шлюза вместо unifi.ui.com и обновите страницу после установки.
Туннель подключён, но устройство выходит напрямуюПроверьте, назначена ли устройству или его сети политика с созданным VPN-профилем. Проверяйте внешний IP именно этого устройства; IPv6 через AWG не поддерживается.
Не проходит проверка связиПроверьте доступность AWG-сервера, параметры конфига и включение 1.1.1.1 в AllowedIPs.

Переход с версии 0.2.x

Автоматического переноса подключений нет. Сначала сохраните оригинальные AWG-конфиги вне шлюза. Удалите или перенастройте связанные политики и VPN-профили UniFi, затем полностью удалите старую интеграцию командой ниже. После этого установите v0.3.2 и добавьте подключения заново.

УДАЛЯЕТ КОНФИГИ И КЛЮЧИ
sh /data/awg-native/uninstall.sh --purge

Удаление интеграции

Сначала удалите или перенастройте связанные политики и VPN-профили UniFi. Для удаления интеграции с сохранением конфигов и ключей:

СОХРАНИТЬ КОНФИГИ
sh /data/awg-native/uninstall.sh

Для полного удаления используйте параметр --purge, как в команде выше: он удаляет и конфиги с ключами. После удаления обновите страницу UniFi.
