UNIFI-AMNEZIAWG / INSTALLATION

Install AmneziaWG
on your UniFi gateway.

Set up Amnezia on UniFi using the AmneziaWG 3.1 protocol: from a configuration file to VPN routing for selected devices. Instructions for integration version 0.3.2.

Source reviewed · 2026-11-06

Installing Amnezia on UniFi with this project means adding an AmneziaWG protocol client to UniFi OS. It connects your gateway to an AWG server and lets you select devices for VPN routing with native UniFi policies. The desktop AmneziaVPN app is not installed on the gateway.

Supported UniFi models: UDR7, UDM and UDM Pro

You need an ARM64 / aarch64 UniFi gateway, root access over SSH and an AmneziaWG 3.1 client .conf. Both the server and exported configuration must use AWG 3.1. The integration does not provide a VPN server.

The code requires at least OS 5.1.33 and Network 10.6.101. Version numbers are only the first check: the installer also verifies paths and SHA-256 hashes of active interface files. The catalog includes Network 10.6.101 and 10.6.109. The “+” notation from the README does not imply support for every future update. Testing on UDM SE has not been separately confirmed.

Before installation: back up UniFi, keep SSH access to the gateway and disable automatic updates for UniFi OS and Network. Updates have not been tested; the integration is not guaranteed to survive them. This project is not affiliated with Ubiquiti.

Get an AmneziaWG 3.1 configuration for your router

If you manage your own server in AmneziaVPN, first check that it uses the AmneziaWG 3.1 protocol. Then open Share → AmneziaWG native format in the app and save the .conf file. This export method is documented in the official Amnezia guide.

UniFi-AmneziaWG requires a native AWG 3.1 configuration with [Interface] and [Peer] sections. A .conf extension alone does not identify the protocol version. The integration does not directly import vpn:// keys. If you use a VPN provider, request an AWG 3.1 file and a separate client key for your router. Export availability depends on the service you use.

Install over SSH

Connect to the gateway as root over SSH and run the command for release v0.3.2:

SSH / SHELL
curl -fsSL https://raw.githubusercontent.com/DjGreeZ/UniFi-AmneziaWG/v0.3.2/install.sh -o /tmp/awg-install.sh && sh /tmp/awg-install.sh

Review the downloader before running it. It downloads this release's package and verifies its SHA-256 checksum against the published file. Engines, the panel and services are installed in /data/awg-native; original interface files are backed up. No on-device compilation is required.

If the installer reports incompatible interface files, keep the error and your UniFi version numbers for an issue report. Do not replace interface files manually.

Your first connection

  1. Open UniFi using the gateway's local IP address. The integration menu does not appear through unifi.ui.com.
  2. Go to Settings → VPN → AmneziaWG Client, select the add-connection button and upload your native AmneziaWG 3.1 configuration.
  3. Select the newly created profile in native routing policies. Assign the intended devices or networks and enable Kill Switch.
  4. Check the connection state and external IP from a device assigned to the policy. Confirm that traffic counters increase.
  5. To add failover, create a separate connection and select it as the primary connection's backup. Each connection needs its own AWG client key.

The configuration must contain one [Peer] and one IPv4 tunnel address. AllowedIPs must include 1.1.1.1 for connectivity checks. IPv6 through the VPN is not supported. Configure device DNS in UniFi; the DNS setting in the AWG file is not automatically applied to the LAN.

What to check if the VPN does not work

SymptomFirst check
The AmneziaWG Client section is missingUse the gateway's local IP instead of unifi.ui.com and refresh the page after installation.
The tunnel is connected but a device uses its direct connectionCheck that the device or its network is assigned to a routing policy using the created VPN profile. Test the external IP from that device; IPv6 is not routed through AWG.
The connectivity check failsCheck AWG server reachability, configuration parameters and whether AllowedIPs includes 1.1.1.1.

Migrating from 0.2.x

Connections are not migrated automatically. Save the original AWG configurations outside the gateway first. Remove or reassign the related UniFi policies and VPN profiles, then fully remove the old integration using the command below. Install v0.3.2 and recreate your connections afterwards.

DELETES CONFIGURATIONS AND KEYS
sh /data/awg-native/uninstall.sh --purge

Removing the integration

First remove or reassign the associated UniFi policies and VPN profiles. To remove the integration while keeping configurations and keys:

KEEP CONFIGURATIONS
sh /data/awg-native/uninstall.sh

For full removal, use --purge as in the command above: it also deletes configurations and keys. Refresh the UniFi page after removal.
