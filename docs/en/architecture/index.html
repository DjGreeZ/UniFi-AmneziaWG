How traffic reaches the VPN

The integration connects UniFi’s native WireGuard client to the AmneziaWG engine. UniFi selects devices and traffic through its routing policies; a local service forwards that traffic to an external AWG server.

  1. LAN deviceA UniFi routing policy selects traffic for the VPN.
  2. Native WireGuard profileSends traffic to the local address 127.0.0.1.
  3. Local adapterThe awgb1…4 interface receives traffic inside the awgm network namespace.
  4. AmneziaWG engineA routing table selects the primary or backup awgo1…4 interface.
  5. External AWG serverAccepts the VPN connection using the imported client configuration.

Each connection gets its own local adapter keys and UniFi profile. Separate routing tables and NAT operate inside awgm. The amneziawg-go engine runs in userspace and comes prebuilt, so no compilation on the gateway is required.

How failover works

The service checks HTTPS connectivity to 1.1.1.1 through each tunnel and checks for a handshake. Two failed checks mark the primary tunnel unavailable. If its assigned backup is enabled and healthy, the route switches to that connection.

The native UniFi WireGuard profile stays in place, preserving its routing policies. With automatic return enabled, three successful checks of the primary allow traffic to switch back. Switching time depends on how long the checks take; there is no guaranteed interval. The service does not recursively follow a chain of backup connections.

If no usable exit is available, the service installs a blocking route. Also enable UniFi’s native Kill Switch for the routing policy, as described in the installation guide.

Reboots and updates

A local copy of the components can restore missing files and services after a reboot. UI restoration applies only to recognized UniFi files. Unknown updated files are not replaced with older backups.

Recovery does not guarantee compatibility with a new UniFi OS or Network release. Automatic updates have not been tested. Check compatibility and keep a backup before making changes.
