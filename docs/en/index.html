AMNEZIA ON YOUR ROUTER

How do I connect Amnezia
to UniFi?

Install the integration over SSH, upload an AmneziaWG configuration and choose devices for VPN routing in UniFi policies.

The project adds an AmneziaWG protocol client to UniFi OS. The VPN connection runs on your gateway, and devices on your home or work network use it according to your routing rules. You need an AWG server and its configuration file to get started.

How to install AmneziaWG on UniFi: step-by-step guide →

01 / CONNECTIONS

Import your config

Upload a native AmneziaWG 3.1 .conf from your AWG server. The integration creates a local WireGuard profile that you can select in UniFi routing policies.

02 / FAILOVER

Choose a backup

Select another connection as the backup exit. Your policies stay in place when the primary server fails. Automatic return to the primary is configurable.

03 / MONITORING

Keep an eye on traffic

View transfer rates, monthly traffic, availability history and switching events. Traffic measurements remain associated with the original profile.

COMPATIBILITY

Tested devices.
Clear boundaries.

Designed for ARM64 UniFi gateways. Installation requires root access over SSH. Prebuilt AWG engines are included in the package.

This is an independent, experimental project. Installation modifies UniFi interface files; make a backup before getting started.
